# Day 06 - Loops and Number Problems

Programs practiced in Day 06:

1. `for_loop_1_to_10.c` - print numbers from 1 to 10 using a `for` loop.
2. `while_loop_10_to_1.c` - print numbers from 10 to 1 using a `while` loop.
3. `even_numbers.c` - print even numbers from 2 to 18.
4. `multiples_of_5.c` - print multiples of 5 up to 50.
5. `sum_1_to_10.c` - calculate the sum from 1 to 10.
6. `sum_even_between_1_and_20.c` - sum the even numbers strictly between 1 and 20 (result: 90).
7. `factorial.c` - calculate factorial, including 0! = 1, and reject negative input. This int-based version accepts inputs from 0 to 12.
8. `sum_of_digits.c` - calculate the sum of a number's digits; the minus sign is not counted as a digit.
9. `count_digits.c` - count the digits, including the special case that 0 has one digit.

All programs are separate so each can be run independently in OnlineGDB.
